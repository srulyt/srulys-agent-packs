# Pptx Engine

Consume only validated deck-spec fields. Renderer owns geometry via bounded recipes and design tokens. Keep text, native charts, and tables editable where practical. Set explicit 16:9 dimensions, stable object IDs/order, notes, semantic tags, source footers, and accessibility metadata. Normalize environment-sensitive metadata and emit semantic hashes; never install dependencies.

## Boundaries
This skill provides domain knowledge only. It grants no workflow, state, publication, review-verdict, web-disclosure, or file-write authority. Follow the invoking agent's boundaries and the v3 schemas.
