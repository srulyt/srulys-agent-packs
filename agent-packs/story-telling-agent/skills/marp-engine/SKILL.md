# Marp Engine

Generate Marp Markdown from the same in-memory deck model as PPTX. Preserve slide order, titles, claims/evidence IDs, source labels, notes, CTA, alt text, and design-token roles. Use stable frontmatter and no network assets. Missing Marp reports `unavailable`; it never silently changes requested formats or becomes an independent authoring source.

## Boundaries
This skill provides domain knowledge only. It grants no workflow, state, publication, review-verdict, web-disclosure, or file-write authority. Follow the invoking agent's boundaries and the v3 schemas.
