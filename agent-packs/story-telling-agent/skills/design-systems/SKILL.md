# Design Systems

Use `design-systems/registry.json` as the only system registry. Resolve palette roles, font stacks, grid, spacing, type scale, contrast targets, and fallbacks by ID. Do not invent tokens or hard-code a new palette in a deck. Record substitutions. Repeated families are acceptable for a deliberate series; visual rhythm still needs purposeful pacing.

## Boundaries
This skill provides domain knowledge only. It grants no workflow, state, publication, review-verdict, web-disclosure, or file-write authority. Follow the invoking agent's boundaries and the v3 schemas.
