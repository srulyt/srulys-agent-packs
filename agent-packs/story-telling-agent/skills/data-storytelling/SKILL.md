# Data Storytelling

Choose by relationship: comparison→bar/dot, trend→line, composition→stacked bar (pie/donut only valid simple part-to-whole), distribution→histogram/box, correlation→scatter, flow→Sankey/process when justified. Include units, source/evidence IDs, focal datum, annotation, missing-value policy, axis policy, and color semantics. Bars start at zero unless a visible justified exception exists. Do not use 3D, dual axes by default, or encode meaning only with color.
