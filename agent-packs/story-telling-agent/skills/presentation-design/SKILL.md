# Presentation Design

One primary message per slide. Select layouts by assertion/evidence fit, not decoration. Use a grid, generous margins, clear alignment, intentional whitespace, and a dominant focal point. Vary layout purposefully across title, section, evidence, comparison, process, timeline, chart, image, matrix, recommendation, and CTA. Use restrained type scale, minimum readable sizes, short line lengths, and no ornamental card grids or hairlines by default.
