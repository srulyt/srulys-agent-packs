# Pptx Visual Qa

Inspect every 150-DPI slide and a contact sheet. Score decision clarity, arc, headline sequence, assertion/evidence fit, hierarchy, composition, rhythm, typography, imagery, chart choice, brand fit, accessibility, and executive credibility. Compare retries against prior renders, confirm targeted improvement, and detect regressions. Missing render engine yields `unverified-needs-user`, never pass.

## Boundaries
This skill provides domain knowledge only. It grants no workflow, state, publication, review-verdict, web-disclosure, or file-write authority. Follow the invoking agent's boundaries and the v3 schemas.
