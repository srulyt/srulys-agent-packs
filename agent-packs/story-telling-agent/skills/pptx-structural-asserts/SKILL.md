# Pptx Structural Asserts

Check dimensions/count/order, unique IDs, title sequence, semantic object tags, notes, source/evidence lineage, alt/decorative semantics, reading order, contrast intent, minimum type, safe areas, overlap/overflow, crops, glyphs/fonts, chart units/sources/axes/zero baseline, and PPTX/Marp semantic parity. Checks emit stable IDs and evidence; unavailable visual rendering cannot pass visual checks.

## Boundaries
This skill provides domain knowledge only. It grants no workflow, state, publication, review-verdict, web-disclosure, or file-write authority. Follow the invoking agent's boundaries and the v3 schemas.
